### Week 4 Objectives:

* Learn asynchronous messaging patterns for decoupled systems.
* Practice backup/reliability and containerization basics.
* Build a first CI/CD pipeline.

### Week 4 Achievements:

* Built a decoupled workflow using SQS for buffering and SNS for fan-out notifications.
* Configured an AWS Backup plan with a retention policy for EC2/RDS resources.
* Wrote a Dockerfile, built an image, and ran it locally as a container.
* Deployed a containerized service on Amazon ECS with a basic task definition.
* Set up a CodePipeline that automatically builds and deploys on a new commit.
* Understood how messaging, backup, and CI/CD together improve a system's reliability and operational speed.
