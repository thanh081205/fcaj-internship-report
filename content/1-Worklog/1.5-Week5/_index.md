### Week 5 Objectives:

* Build a fully serverless backend and connect it to a frontend.
* Automate serverless deployments with AWS SAM.
* Add authentication to a serverless application.

### Week 5 Achievements:

* Built a serverless CRUD backend with Lambda, API Gateway, and DynamoDB.
* Connected a static frontend (hosted on S3) to the serverless API.
* Automated the build/deploy cycle of the serverless stack using AWS SAM instead of manual console steps.
* Added user sign-up/sign-in with Amazon Cognito and validated JWTs on the API side.
* Wired SQS/SNS into the serverless workflow for asynchronous event processing.
* Understood the full serverless application lifecycle, from local development to automated deployment.
